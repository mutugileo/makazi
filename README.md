# makazi

Makazi tenant mobile application built with Flutter, Riverpod, and Supabase.

## Overview
Makazi is a multi-company property management platform. This mobile app provides tenants with account management, real-time billing breakdown, seamless rent payment workflows (M-Pesa and bank transfer), maintenance repair reporting, and property manager messaging.

## Key Features
- **Authentication**: Secure phone and password sign-in with temporary password rotation and PIN support.
- **Billing & Statements**: Real-time rent ledger, balances, monthly dues, and line-item utility breakdown (water, garbage).
- **Rent Payment Flow**: Pay rent flows with validation, receipts history, and balance reconciliation.
- **Maintenance & Repairs**: Ticket submission with severity level, photo attachments, and real-time status updates.
- **Direct Messaging**: In-app communication with property management staff.

## Getting Started

### Prerequisites
- Flutter SDK 3.x+
- Dart SDK 3.x+

### Setup & Run
```sh
flutter pub get
flutter run
```

### Running Tests
```sh
flutter test
flutter analyze
```
